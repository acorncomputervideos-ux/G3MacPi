# 2026-11-17 — HFS Plus reader

- `HfsPlusVolume`, read-only, written from TN1150: volume header (also
  inside an HFS wrapper), catalog and extents-overflow B-trees, folder
  listing, lookup by name and by Finder type, fork reads with overflow
  extents.
- Lookups need no Unicode case-folding table. They walk the index by the
  numeric parentID, then scan that folder's records, comparing ASCII
  names case-insensitively.

  B-tree header's `attributes` field is at 38, not 39. A sabotage run
  that puts 39 back fails all HFS+ tests.

  Installing `hfsprogs`/`hfsutils` to cross-check against independent
