  bootinfo format at the start of Mac OS's boot file.
- `of::parse_bootinfo`: elements, case-insensitive tags, skipped unknown
  elements, several sections, entities (path entities only in the boot
  script), icons with defaults, and the offset of the binary data that
  follows.

  with the element's name, and spaces around `=`); the tests added for

  are caught now.
