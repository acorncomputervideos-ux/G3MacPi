# 2026-11-17 — Back to the independent design; Milestone 2 step 1 (CPU)

## Decision
Owner asked to return to the original plan and to prioritise work that
needs no hardware testing. ADR-0011: DingusPPC port reverted (code identical
to 02b7989 again — the Milestone 1 kernel, plain Circle Step51.1.1). Its CPU
test vectors are kept as reference data (`tests/vectors/dingusppc/`).

## New
- `core/cpu/ppc750/`: PowerPC 750 interpreter — integer, branch, CR,
  load/store, SPR/MSR/SR, time base/decrementer, exceptions and interrupts.
  Details and known gaps: docs/hardware/ppc750-cpu.md.
- `core/mem/flat_memory.h`: contiguous big-endian guest memory.
- Tests: all 5620 integer vectors (`cpu/vectors/integer`), 32 hand-written
  unit tests via an independent test encoder (`tests/unit/cpu/ppc_asm.h`).
- `g3_cpu_bench`: ~160 M guest instr/s on the CI-class Xeon (host figure).

## Verified (Linux container)
- 57/57 unit tests pass with gcc + ASan/UBSan, and with clang.
- Deliberately breaking `or` and the arithmetic shifts makes the vector test
  fail (196 failures), so the vector runner really checks results.
- Core still compiles freestanding for AArch64 with -Werror (check-core.sh).
- Pi image still builds (324,240 bytes, the same kernel as Milestone 1).

## Not verified / pending
- Nothing new needs the Pi. The Milestone 1 hardware check (keyboard, mouse,
  SD log) is paused while the owner is busy.
