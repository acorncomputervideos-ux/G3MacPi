# G3MacPi

An independently developed, **bare-metal PowerPC Macintosh G3 (Blue & White)
emulator** for the **Raspberry Pi 400**, built on the
[Circle](https://github.com/rsta2/circle) bare-metal framework (host
infrastructure only).

## Status

**Phase 0: research and architecture.** No emulator code exists yet, and
nothing is claimed to work.
